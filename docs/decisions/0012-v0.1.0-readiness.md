**Error cases (criterion 4).** Each row of the spec's table is covered by a
test in `test/cli/commands.test.ts`:

| Situation | Tests |
|---|---|
| No prompt in time | "explains a login that shows no prompt, including the network hint" |
| No login in progress, or the CLI exited | "complete without login explains the next step"; "ends the login when the CLI gives up" |
| Empty or malformed response | "rejects an invalid pasted code without ending the login"; the strategy tests, including crafted callback addresses |
| Provider rejects the code | "reports a wrong code without echoing it"; "reports at once when the CLI's listener rejects the sign-in" |
| Provider unreachable | the network hint in login and install failures |

**Secrets (criterion 5).**

- Tests check that codes and callback addresses are never echoed: "without
  echoing", "does not echo a code next to an unknown agent", and the masking
  tests in `test/core/output.test.ts`.
- The session state holds only the prompt URL (`SessionState`).
- Agent-Bridge writes no logs.
- Two independent reviews (Phase 4 and Phase 5) found no leak.
